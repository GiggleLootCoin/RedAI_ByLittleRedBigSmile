# RedAI

**A standalone Android AI app created and developed by Red aka LittleRedBigSmile.**

This repository is the independent RedAI Android build. It does not modify or depend on the existing RedUI, RedAI, Little Red's Big Studio, or RED-LIVE repositories.

## Build direction
- Native Android application (not a web wrapper)
- Premium black / vivid crimson visual identity
- Chat-first interface with clear local/private status
- Designed for on-device inference and offline use
- Model packaged with the final distributable so users do not have to locate or import a GGUF

## Honest build status
This is the clean standalone application foundation. The inference runtime and licensed model asset still need to be integrated and tested before this can be described as a complete offline AI app. No model is silently downloaded or claimed to be bundled at this stage.

## Build
GitHub Actions builds a debug APK on pushes and pull requests. See the Actions tab for the artifact.
